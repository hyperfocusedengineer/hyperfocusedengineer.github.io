// how it’s built

One monorepo, many apps

Each iPhone app is a thin shell over a shared host: the same launcher, search, favorites and detail sheet, with its own name, colours, icon and list of micro-apps.

Micro-apps never touch native code directly. They get one host services object for haptics, storage, the step counter and links, so each app compiles in only the device features its micro-apps actually use.

Tests check every app on each build: the right native modules and permission strings, unique names and icons, and very little overlap between sets, so each app stands on its own.
